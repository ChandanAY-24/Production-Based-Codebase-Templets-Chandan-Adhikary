# Reference Artifacts
> Directory: `docs/reference-artifacts/`
> Purpose: Supplementary architecture specs, wireframes, checklists, and schema diagrams

---

## Catalog & Guidelines
- Store static assets, mockups, design tokens, and baseline schema dumps here.
- Maintain human-readable naming conventions:
  - `wireframe-<feature>-v<version>.png`
  - `schema-dump-<timestamp>.sql`
  - `checklist-<milestone>.md`
- Any artifact linked from `docs/SPEC.md` or `docs/DESIGN.md` should reside in this directory.
